# Fuse meaning and traits through a grounding map

The semantic space and the nine-axis space become one search space when they are joined by a measured, per-axis **grounding map**, not by a learned alignment. The grounding map records which axes the concept text actually carries (and so can cross-check) and which it does not (and so must be stated explicitly and verified by code). With 15 text-bearing seeds, every learned fusion in the literature (CCA, CLIP-style contrast, MoleculeSTM-style joint encoders) is out of reach by two to four orders of magnitude. What works at this scale is a training-free shared coordinate system: every item is described by its similarity to a shared set of anchor cases, measured semantically for text and by a Gower distance over the axes for structure (ASIF / relative representations), plus a "text-claimed axis record" extracted blind from the concept text and compared field by field with the code record. The joint boundary is then a versioned object: an axis trust region as the hard gate, a conformally calibrated semantic radius around the anchors, and a text–axis consistency check on the carried axes. It grows mainly when verified LLM proposals become new anchors, and only occasionally through architect locks and rejections. The LLM explores inside this boundary in an LLM-Modulo loop: the code is the hard critic, gaps in axis coverage are sent back as targets, and the grounding map decides whether each gap is phrased in words (carried axes) or as explicit numeric targets (uncarried axes). No published system builds a single archive that mixes free concept text with code-computed descriptors and ablates it against each space alone, so the evaluation itself would be a contribution. Five experiments, runnable now with the 15 seeds, the 1,050-variant pool, local Ollama encoders and existing labels, can test whether the joint mode beats either space alone, and each has a stated result that would falsify it.

## Fifteen anchors rule out learned alignment but not a shared space

The obvious way to make two spaces "understand each other" is to learn a map between them. At this data scale that is not supportable. Linear CCA is ill-posed when the sample size is smaller than the dimension. Even with structured regularization at n=153, a reduced-feature model's cross-validated score was overly optimistic and its test correlation was only **0.044** ([Tuzhilina, Tozzi & Hastie, full text](https://pmc.ncbi.nlm.nih.gov/articles/PMC10274416)). On 15 seeds against a 1024-d bge-m3 vector, canonical correlations would be near 1 by construction and carry no information. Contrastive alignment is worse: CLIP used 400M pairs, and the structure–text analogue closest to this project, MoleculeSTM, trains on more than **280K** structure–text pairs ([ASIF comparison, full text](https://arxiv.org/pdf/2210.01738); [MoleculeSTM, abstract](https://arxiv.org/abs/2212.10789v3)). Even MoMu, which explicitly addresses scarce pairs by starting from separately pretrained encoders, used about **15.6K** graph–document pairs. Its authors also warn that texts which do not describe structure create spurious correlations ([MoMu, full text](https://ar5iv.labs.arxiv.org/html/2209.05481)). That warning matches this project's finding that concept text does not track heights.

The method that does work at tiny n is **anchor-indexed (relative) representation**. ASIF represents each item by its cosine similarity to every anchor *in its own modality*. Because both modalities are indexed by the same anchor pairs, they share a space with no training, each dimension reads as "similarity to anchor i", and anchors can be added or removed without retraining. Adding just **100 domain pairs** raised EuroSAT accuracy from 29.4% to about 82% ([ASIF, full text](https://arxiv.org/pdf/2210.01738)). Relative representations formalize the same idea and show invariance to rotations and rescaling of the latent space ([Moschella et al., abstract](https://arxiv.org/abs/2209.15430)). For Massing Explorer 2.0 the anchors are the seeds. A concept text gets the profile of its bge-m3 similarities to the anchor texts. Any structure, including the 1,050 text-free variants, gets the profile of its axis similarities to the same anchors' records, using a Gower distance in which unknown axes (loading, geometric character) drop out of the average rather than receiving defaults ([Gower's distance, full text of reference page](https://en.wikipedia.org/wiki/Gower%27s_distance)). A text query can then rank text-free variants by profile match, which gives the variants a semantic address without inventing text for them. ASIF's own settings (top-k=800, p=8) assume millions of anchors. With 15, the top-k must be around 3–5.

The second shared coordinate system is a **question-dimension record**. CQG-MBQA builds embeddings whose dimensions are yes/no questions answered by a model. It matched LLM answers about **96%** of the time, at a cost of about **$31** for roughly 10K questions over 1,000 texts, and it pays a measurable quality price for interpretability (STS 77.6 against 85.9 for a black-box encoder) ([Sun et al., ICLR 2025, full text](https://arxiv.org/html/2410.03435v1)). This project does not need question generation, because the nine axes already define the questions. "Is the gym in the same mass as the cafeteria?" is one co-location bit, "Are all three masses linked?" is the topology axis, and so on. For a text, a local model answers the questions *from concept and intent alone*. For a structure, code answers them exactly. The result is a "text-claimed axis record" in exactly the trusted record's coordinates, and its per-field disagreement with the code record is the most direct measure of where the two spaces understand each other.

The recommended joint representation therefore carries four things for every item, held together rather than collapsed into one vector:

| Component | Source | Exists for | Role |
|---|---|---|---|
| Axis record **a** | code (axes-v1) | every valid structure | trusted coordinates; hard gate |
| Semantic vector **s** | bge-m3 on concept + intent | texted items | creativity, reframing, retrieval, novelty |
| Anchor profile **r** | similarity to anchor set K, computed separately in S and in A | every item (S-profile only for texted items) | the shared coordinate system |
| Text-claimed record **q** | blind local-model extraction, carried axes only | texted items | consistency check; grounding strength |

These four are bound by a joint distance, D(i,j) = Σₖ wₖ·dₖ(aᵢ,aⱼ) + w_s·(1 − cos(sᵢ,sⱼ)), with Gower partial distances per axis (Hamming on the 36 co-location bits, range-normalized heights, categorical topology, Jaccard on floors per department). Off-the-shelf encoders do not rescue the alternative of asking one embedding to be "similar with respect to heights". On C-STS, zero-shot bi-encoders score Spearman **about 2 or below** on aspect-conditioned similarity despite strong ordinary STS, and even fine-tuned models stay **below 50** ([Deshpande et al., EMNLP 2023, full text](https://ar5iv.labs.arxiv.org/html/2305.15093)). Instruction-aware encoders such as qwen3-embedding are worth one cheap test, but the expected effect is weak. Pilot 01c already found qwen3-embedding 0.6b non-credible on paraphrase invariance (6 of 15 own-original matches against bge-m3's 10) (`pilots/p01c-robustness/results/FINDINGS.md`).

## A per-axis grounding map lets each side correct the other

"Understanding each other" has a concrete, measurable meaning here. For each axis, the system knows how much the semantic side determines it, in both directions. Call this the grounding map G, one entry per axis. It combines three measurements the project can already make. **Correspondence** asks whether semantic distance tracks axis distance: currently ρ≈0.40 for topology, 0.15–0.19 for program organization and balance, and near zero for heights and vertical organization (`grounding/correspondence_v1.json`). **Forward recoverability** asks whether a blind extractor reading only the concept text recovers the axis value. **Expressibility** asks whether an axis value written into text by an LLM can be read back by a blind extractor. If expressibility fails, the vocabulary cannot carry that axis at all, and the failure is not the generator's.

This is the faithfulness logic of data-to-text evaluation applied axis by axis. QAGS scores consistency by asking the same questions of source and output and comparing the answers. It had "substantially higher correlations" with human factual-consistency judgments than other automatic metrics ([Wang, Cho & Lewis, ACL 2020, abstract](https://aclanthology.org/2020.acl-main.450)). Cycle training frames faithfulness as consistency between a data-to-text and a text-to-data model, and approaches fully supervised performance from **100** samples ([Wang et al., ACL 2023, abstract](https://aclanthology.org/2023.acl-long.160)). DStruct2Design makes the same split for floor plans. Self-consistency checks whether the record is internally valid. Prompt-consistency checks whether the record matches what was asked: requested against produced room count and area, and graph edit distance to the input bubble diagram ([Luo et al. 2024, full text](https://arxiv.org/pdf/2407.15723)). The nine axes are this project's questions, and code supplies the answer key for free. That is a rare advantage over annotation settings, where ground truth is the expensive part.

Extraction reliability must be measured, not assumed. A variance audit of LLM annotation found that prompt paraphrases shifted outcomes by about **3–28 points**, role framing by **15.76–85.12 points**, and that average cross-model κ was **0.026**. It recommends at least 3 paraphrases, 10 or more samples and 2 models, with escalation or redesign when κ < 0.4 ([arXiv 2601.02370, full text](https://arxiv.org/pdf/2601.02370)). That setting was business evaluation, not geometry, so the numbers are a warning rather than a forecast. QDAIF found AI–human label agreement of **73%**, equal to human–human agreement, rising to **95%** when the neutral middle category was excluded ([Bradley et al., ICLR 2024, full text](https://arxiv.org/html/2310.13032v4)). Coarse low/mid/high bins for heights will extract more reliably than exact floor counts.

With G measured, each side informs the other in a specific way. **Axes inform semantics** in three ways. They decide which semantic agreements count as evidence: on carried axes, semantic neighbours that disagree in axis values are flagged as inconsistent, never silently resolved, as the core contribution requires. They tell the LLM which traits its text cannot be trusted to imply, so its structured record must state those traits explicitly. And they give text-free variants a semantic address through anchor profiles. **Semantics informs axes** in two ways that the project's own evidence supports. First, semantic neighbourhoods reveal which axis differences are strategic rather than incidental. In Pilot 01b, on the items where the architect departed from structure, bge-m3 concept-plus-intent sided with the architect, while both LLM judges sided with structure (`pilots/p01c-robustness/results/FINDINGS.md`). A small set of axis weights wₖ can therefore be fitted so that weighted axis distance best matches semantic distance among texted seeds. Fitting is selected on two runs and tested on the third, and the result is compared, with no new labels, against the "defining move" weights the architect already expressed in Pilot 3: special education and core academic moves define a strategy, administration alone sits on the boundary, and supporting program does not (`pilots/p03-expansion/results/FINDINGS.md`). Second, semantic clusters can split one axis cell into distinct organizing ideas, or merge cells the axes keep apart. That is the main signal for proposing a new soft axis, discussed below.

There is a ceiling on what this mutual mapping can show. If forward recoverability turns out high on every axis, the text carries nothing the axes do not, and the semantic side's value is novelty and reframing rather than grounding. If it is near zero everywhere, the two spaces are independent, and "joint" reduces to a weighted sum of unrelated terms. The interesting and expected outcome is a partition into carried and uncarried axes. The current correspondence numbers point that way, but they treat the 105 seed pairs as independent observations. Pairs share seeds, so those p-values are too small. They need a Mantel test that permutes item identities, and with small n a strong correlation can still be non-significant: the worked example in the cited chapter had r=0.939 with p=0.1 ([Applied Multivariate Statistics, Mantel chapter, full text](https://uw.pressbooks.pub/appliedmultivariatestatistics/chapter/mantel-test/)).

## The joint boundary is a versioned trust region that grows from verified proposals

The core contribution rules out any region or membership rule built from one system. The literature offers a well-tested template for a bounded region that adjusts itself in mixed categorical/numeric spaces: the trust region from Bayesian optimization. CASMOPOLITAN defines its categorical region as all points within Hamming distance Lʰ of the best point, and a TuRBO-style box on continuous variables. It expands after 2 consecutive successes, shrinks after 40 consecutive failures (factors 1.5 and 0.667), and restarts when collapsed. Its mixed kernel, λ(kₓ·kₕ) + (1−λ)(kₕ+kₓ) with λ=0.5, can be passed as a precomputed Gram matrix to one-class methods ([Wan et al., ICML 2021, full text](https://arxiv.org/pdf/2102.07188); [scikit-learn OneClassSVM docs](https://scikit-learn.org/0.18/modules/generated/sklearn.svm.OneClassSVM.html)). IC MAP-Elites adds the conditional neighbourhood: designer-locked elements are preserved in every suggestion while the rest evolves ([Alvarez et al., full-text excerpt](https://ar5iv.labs.arxiv.org/html/2003.03377)). A lock is a trust region with zero radius on the locked axes.

The proposed joint membership rule uses both systems, asymmetrically and transparently. A candidate is **inside** when it passes three tests. It must be **axis-grounded**: within the axis trust region of some anchor, honouring locks and hard rules such as the custodial rule. It must be **semantically related**: its semantic position, from its own text or its anchor profile, lies within a radius of the anchor set. And it must be **consistent**: its text-claimed record agrees with its code record on the carried axes. A candidate that passes the axis gate and one of the other two tests is **provisional**, admitted under a per-version quota. Everything else is **outside**. A weighted sum would hide which space admitted a candidate. That is a design argument, not a sourced result: no paper formally studies AND/OR membership combining a text-embedding region with a structured-descriptor region. With 15 points in 1024 dimensions, the semantic radius should be a k-NN rule, not a density. Lei, Robins and Wasserman warn that conformal regions lose efficiency in higher dimensions even when coverage holds. At n=100 in 2-D their set had coverage 0.886 and measure 35.6 against an oracle of about 28 ([Lei, Robins & Wasserman 2013, full text](https://www.stat.cmu.edu/~brian/rm/764-2018/week02/lei-robins-wasserman-2013-distribution-free-prediction-sets.pdf)). Split conformal around a nearest-anchor distance still gives an honest leave-one-out threshold, with granularity no finer than about 1/16 at 15 anchors. That is enough for three bands, not for fine control.

The boundary updates through explicit, logged operators. Each update produces a new version: anchor set, trust radii, locks, semantic radius, grounding map and quota. The **main** growth operator is mechanism-driven, not human-driven. An LLM proposal that passes the code gate *and* the consistency test becomes a new anchor, so the semantic and axis sides grow together. This is how the space stays tied to the LLM's creativity without silent drift. **Rejections** shrink the region locally, in the spirit of SVDD's use of labelled negatives to tighten a description ([Tax & Duin 2004, abstract](https://mlanthology.org/mlj/2004/tax2004mlj-support/)). **New concerns** follow AURORA: when descriptors change, every stored item is re-described and re-inserted, and the distance parameter is reset so the archive's maximum size stays constant ([Cully 2019, full text](https://arxiv.org/pdf/1905.11874)). CVT-MAP-Elites makes that capacity cap explicit, with a fixed number of niches regardless of dimensionality ([Vassiliades et al., abstract](https://arxiv.org/abs/1610.05729)). Since the axes are code-computed, adding a tenth axis means recomputing it for 1,050 variants and rebuilding a CVT with the same K. **Natural-language user input** goes through the joint space itself. A request such as "more stacking, less spread" is embedded and read through the grounding map. If it touches a carried axis, it becomes a semantic bias and its axis effect is checked. If it touches an uncarried axis (heights, vertical organization), a reformulator turns it into an explicit axis constraint that code verifies. This is the sense in which the space is dynamic from user input without making the human the mechanism. Luminate offers the HCI precedent: a user types a new dimension, and the LLM generates its values and re-labels existing responses ([Suh et al., CHI 2024, full text](https://arxiv.org/html/2310.12953v3)). In this design such dimensions sit beside the nine axes as soft, LLM-judged axes, never as trusted ones.

Expectations about learned preference should stay modest. Preference-learning emitters in IC MAP-Elites produced more diverse populations, but their 52-response user study found no significant difference in final-solution rankings (Friedman p=**0.764**) ([Gallotta et al. 2022, full text](https://arxiv.org/pdf/2210.13839)). UC-ME, which moves a window over a floor-plan descriptor map instead of learning a model, matched simulated users' criteria better than unguided MAP-Elites but had lower coverage ([Bahrami/Liapis et al., GECCO 2023, full text](https://ar5iv.labs.arxiv.org/html/2304.01642)). Explicit, inspectable operators such as locks, rejections and new axes fit the architect's scarce attention better than implicit models. When the architect is consulted at all, it should be in one batch of the 3–5 candidates nearest the band thresholds, following the logic of active level-set estimation ([Gotovos et al., IJCAI 2013, abstract](https://www.ijcai.org/Abstract/13/202)).

## The LLM explores freely but lands on code-verified coordinates

The generator side has the strongest precedent base. LLM-Modulo pairs an LLM generator with "hard critics" that must all approve, and "soft critics" that may be LLM-based. It forbids LLMs from acting as hard critics ([Kambhampati et al., ICML 2024, full text](https://arxiv.org/html/2402.01817v2)). On TravelPlanner, the loop raised GPT-4-Turbo's pass rate from **4.4% to 20.6%**. Critics were non-additive: format-only critics reached 1.1%, hard-only 1.6%, and all critics together 20.6% ([Gundawar et al. 2024, full text](https://arxiv.org/pdf/2405.20625)). Self-critique without an external signal lowered accuracy on every benchmark tested; for example, CommonSenseQA with GPT-3.5 fell from 75.8 to 41.8 ([Huang et al., ICLR 2024, full text](https://arxiv.org/pdf/2310.01798)). A sound verifier with simple re-prompting keeps most of the benefit of elaborate critique ([Stechly et al., ICLR 2025, abstract](https://arxiv.org/abs/2402.08115v2)). For manual chat batches this is good news. Returning "your proposal landed at axes X; you intended Y" is cheap and probably captures most of the value. The project's own observation that after-the-fact LLM descriptions become placement inventories is the describer failure these papers predict.

Proposal format matters. Strict formats degrade reasoning: GPT-3.5-Turbo scored 56.74 free-form against 25.20 in JSON mode on Last Letter. Answering in natural language first and converting afterwards ("NL-to-Format") performed almost identically to unrestricted text ([Tam et al., EMNLP 2024, full text](https://arxiv.org/html/2408.02442v1)). Seed format v2 should therefore keep concept and intent first, then key moves, then the explicit record, with no target fields ahead of reasoning. Explicit numeric targets land only partly even for countable attributes. Frontier models hit exact word-count targets **57–62%** of the time and small open models **12–15%** ([Ruler, Findings of EMNLP 2024, full text](https://arxiv.org/html/2409.18943v2)). That is why gap steering needs the feedback loop and not one-shot targets.

Gap steering combines two quality-diversity precedents with the grounding map. In-context QD serializes archive elites with their feature values, sorted by distance to the target cell. It asks for proposals at specific or empty cells and found feature-aware templates critical ([Lim et al. 2024, full text](https://arxiv.org/html/2404.15794v2)). ACES samples an under-filled target cell and prompts with its nearest archive neighbours. It notes that landing in *any* new cell matters more than hitting the target exactly ([Pourcel et al. 2023, full text](https://arxiv.org/html/2310.10692v1)). MolLEO shows that LLM edits alone gave modest gains, while the evolutionary loop with oracle scoring did well: a summed score of 17.862 against 13.823 for Graph-GA on 23 tasks. It also used an anchor-similarity filter to stop drift ([MolLEO, arXiv 2406.16976, full text](https://arxiv.org/pdf/2406.16976v3)). This supports a hybrid in which LLM proposals introduce new organizing ideas and the code edit generator fills their axis neighbourhoods. Pilot 3 already showed the second half: code produced about 400 valid strategies the LLM never offered, and only 27 of them resembled anything in runs 02–03 (`pilots/p03-expansion/results/FINDINGS.md`). The grounding map adds the missing piece. Gaps on carried axes can be phrased as natural-language gaps ("no proposal yet separates the commons from the classroom bar"). Gaps on uncarried axes must be stated as explicit axis targets, or filled by code-side variation, because the LLM's text cannot be trusted to move them. Whether natural-language gap descriptions beat numeric empty-cell targets for a semantic generator appears to be untested in the literature, and the project can answer it.

One warning governs the whole design. QDAIF's embedding-feedback variant, QDEF, which scored diversity by cosine similarity between text embeddings and axis labels, reached a human QD score of **0.308** against **0.617** for LLM-judged axes. High scorers converged toward the query text itself ([Bradley et al., ICLR 2024, full text](https://arxiv.org/pdf/2310.13032)). ACES likewise found that an embedding-defined CVT archive produced more valid puzzles, but mostly in cells the training set already covered ([Pourcel et al., full text](https://arxiv.org/html/2310.10692v1)). Embedding similarity must never *be* an axis value. It belongs on the exploratory side (retrieval, novelty, relation), with the axes computed by code.

| LLM-Modulo, TravelPlanner ([full](https://arxiv.org/html/2402.01817v2); [full](https://arxiv.org/pdf/2405.20625)) | External verifiers, not self-critique, carry correctness | Spatial or strategy domains |

Across the five research threads, three elements appear to be new, within the limits of what was searched. The first is a single search space whose membership needs *both* free semantic relation and code-computed strategy traits. The second is an axis-by-axis grounding map that decides where text can cross-check structure and where structure must be stated explicitly. The third is a head-to-head joint-versus-single evaluation in a design domain. The direct joint-versus-single gap may be filled by 2025–2026 GECCO or CAADRIA papers the searches did not reach. ELM, In-context QD's coverage figures and AutoQD were not fully verified.

## Five experiments that can falsify the joint approach

The evaluation literature sets the bar. A recent audit of multimodal fusion across nine datasets found that no complex fusion method reliably beat a simple baseline. Several published fusion methods were "likely worse than simply using the best single modality", and in the audited papers **0%** tuned baselines and **0%** reported significance ([Fusion or Confusion?, arXiv 2512.22991, full text](https://arxiv.org/pdf/2512.22991)). Every experiment below therefore follows the same rules. Arms include S-only, A-only, a naive concatenation (J-concat), the proposed joint (J), and a shuffled control (J-shuffled, with axis records permuted across items). All arms get equal tuning knobs. Selection uses runs 1–2 and testing uses run 3, rotated across all three run orders. Inference uses cluster bootstrap over seeds and exact sign-flip tests over the 15 seeds (2¹⁵ = 32,768 permutations). Everything is scored in common measurement spaces, not each arm's own: A-space cells, a held-out encoder, and seed-family labels. The primary metric, the J configuration and an equivalence margin are written in a dated file before any test run is scored. That file also satisfies the project's process rule that each pilot states its task, its dependencies and their status. Experiment 1 addresses Task 2, which is open. Experiments 2–4 address Task 4 and depend on Experiment 1. Experiment 5 addresses Task 5 and depends on Experiments 1 and 4. Text-reading LLM judges are excluded as truth, because Pilot 01c found they side with structure on 12 of 14 items and would build in a structural bias (`pilots/p01c-robustness/results/FINDINGS.md`).

| # | Task (depends on) | Data | Primary metric | Falsifies the joint approach if |
|---|---|---|---|---|
| 1 | Task 2 (Task 1, resolved) | 15 seeds; axes_v1 | per-axis κ / Spearman against code, and Mantel ρ | no axis is carried above the shuffled-text control, or every axis is carried |
| 2 | Task 4 (Exp 1) | 15 seeds; 1,050 pool | leave-one-run-out cross-modal retrieval MRR | J ≤ max(S, A) or J ≈ J-shuffled |
| 3 | Task 4 (Exp 1) | 15 described expansions; pool | rank of the written concept under anchor imputation | anchor imputation ≤ nearest-seed copy or random anchors |
| 4 | Task 4 (Exp 1–3) | Pilot 3 decisions; runs 1–3 | held-out recall/rejection and bootstrap stability | a single-space boundary matches or beats J on both |
| 5 | Task 5 (Exp 1, 4) | anchors; local LLM; one manual batch | new A-cells × consistency at equal budget | joint steering does not beat axis-only and semantic-only steering |

### Experiment 1: per-axis grounding map

This experiment measures, for each axis, how much the concept text determines it. It uses the 15 seeds' concept and intent text and their axes-v1 records. Key moves are withheld from the extractor, because they name departments and links directly (Task 3 found that key moves name all three links in every seed), so including them would make recovery trivial.

**Arms.** The main arm is blind extraction of each derivable axis from the text: two Ollama models × 3 paraphrased prompts × 10 samples, coarse bins for heights, one prompt per axis, and an all-axes prompt as a secondary condition. It runs against four controls. The first is a majority-class baseline. The second is a shuffled-text control, where each seed's text is scored against another seed's record. The third is an expressibility ceiling: code record → LLM-written text → blind extraction. The fourth redoes the bge-m3 correspondence with Mantel permutation and a cluster bootstrap over seeds, using mxbai, nomic and qwen3 as encoder controls.

**Metrics.** Weighted κ for categorical axes and bits, Spearman or MAE for heights and balance, Jaccard for floors per department, and Mantel ρ with a permutation p.

**Success.** Each axis lands in one of three classes: carried (κ ≥ 0.6 and above the shuffled control), partial (0.4–0.6), or uncarried (< 0.4). Topology is expected to be carried and heights uncarried, consistent with the current correspondence result. This table becomes the grounding map G.

**Falsification.** The joint approach is falsified if no axis beats the shuffled control: the two spaces are then independent, and "understanding each other" has nothing to stand on. It is also undercut if every axis is carried at high κ, because the text then adds no grounding information. If the expressibility ceiling fails on an axis, that points to the vocabulary, not the generator.

### Experiment 2: does the shared anchor space translate between modalities?

This experiment asks whether the shared space lets a concept text find its own structure, and a structure find its own text. It uses the 15 seeds and the 1,050-variant pool. Anchors are built from two runs, so ten seeds are anchors, and the five held-out run's seeds are queries.

**Arms.** Each held-out seed's text ranks the anchor seeds plus all 1,050 variants, and the target is its own record's nearest axis neighbourhood. The arms are:
- **S-only:** nearest anchor by bge-m3, then its axis neighbourhood.
- **A-only:** a text-blind prior that ranks by axis centrality.
- **J-concat.**
- **J:** an ASIF-style profile match with top-k 3–5, plus G-weighted axis terms.
- **J-shuffled:** the S profiles and A profiles of the anchors are mismatched.

The reverse direction, structure query → text, is run too.

**Metric.** MRR of the true record (or of the mean per-axis distance of the top-5 to the true record), with sign-flip tests over the held-out seeds and three rotations.

**Success.** J beats S-only and A-only by a pre-stated margin, and J-shuffled collapses to near A-only.

**Falsification.** J ≤ max(S, A), or J ≈ J-shuffled. The second outcome means the gain comes from extra dimensions, not shared meaning.

A caveat applies: cross-run "structural twins" were defined by structure in Pilot 01b, so they cannot serve as the positives here without favouring A.

### Experiment 3: can text-free variants receive a trustworthy semantic address?

This experiment tests whether a variant with no text can be given a semantic position that matches what an independently written concept for it says. It uses the 15 Pilot 3 representatives that later received ChatGPT-written concepts, plus their pool records.

**Arms.** Each method predicts a semantic vector for each representative from its record alone:
- **ASIF anchor imputation,** with a low-support flag when the nearest anchor is far.
- **Templated textualization** of the record, embedded with bge-m3.
- **Nearest-seed copy.**
- **A random-anchor control.**

**Metric.** The rank of the true written concept's bge-m3 embedding among the 15 concepts, scored with a cluster bootstrap. The template arm also gets a leakage check: if template embeddings correlate with axis distance far more than authored concepts do, the encoder is reading the template's wording.

**Success.** Anchor imputation beats nearest-seed copy and random anchors.

**Falsification.** Imputation ≤ nearest-seed copy, which would mean text-free variants cannot be placed semantically beyond their parent. The joint space would then cover only texted items. A caveat: these concepts were written after the fact and may be placement inventories, so a null result is weaker evidence than a positive one.

### Experiment 4: does the joint boundary separate known insiders from known rejects better and more stably?

This experiment compares the joint boundary with single-space boundaries using only labels that already exist. Positives are the run-3 seeds when the boundary is built on runs 1–2 (same brief, so they should fall inside) and the architect's "add" groups from Pilot 3. Negatives are the rejected heart-link-cut group (10 structures) and the "skip" groups.

**Arms.** Five boundaries are built with the same frozen thresholds:
- **Axis-only:** the existing structural candidate.
- **Semantic-only:** a conformal k-NN radius on bge-m3 or anchor-imputed vectors.
- **J-concat.**
- **J:** the three-test rule.
- **J-shuffled.**

**Metrics.** Held-out recall of positives, rejection of negatives, and boundary stability: Jaccard of membership across a seed bootstrap and leave-one-run-out. The Pilot 01b Pass B labels (16 triplets) serve as a secondary, descriptive check only.

**Success.** J is at least as good as the best single-space boundary on recall and rejection, and more stable.

**Falsification.** A single-space boundary matches or beats J on both. In that case, the joint rule is adding complexity, not information.

### Experiment 5: does joint gap steering find more new, consistent strategies at equal budget?

This experiment tests whether joint steering produces more new, trustworthy strategies than steering from either space alone. It needs the frozen boundary from Experiment 4 and the grounding map from Experiment 1. It runs first with a local Ollama generator (automatable, about 60 proposals per arm), then as one manual frontier-model batch to confirm.

**Arms.** Five arms run at equal budget:
- **Semantic-only steering:** OMNI-EPIC-style nearest-neighbour context plus a semantic novelty demand.
- **Axis-only steering:** empty CVT cells given as numeric targets with distance-sorted exemplars.
- **Joint steering:** carried-axis gaps phrased in words, uncarried-axis gaps as explicit targets, with code feedback of the bare computed-against-intended axes for up to 3 rounds.
- **Random-parent few-shot control.**
- **Self-critique control** with no computed axes.

**Metrics.** All arms are scored in common spaces: newly filled A-space cells counted only when the proposal is valid *and* consistent on the carried axes, held-out-encoder Vendi score ([Friedman & Dieng, full text](https://arxiv.org/html/2210.02410v2)), mean per-axis distance to the requested gap, and validity rate.

**Success.** Joint steering beats both single-space arms on consistent new cells. The self-critique control is expected to be at or below the one-shot baseline, as the literature predicts.

**Falsification.** Joint steering ≤ axis-only on consistent new cells. That would mean the semantic side adds no exploratory reach that code variation and numeric targets do not already provide. Ruling that the semantic side should be dropped is not an option under the core contribution, so the result would instead redirect its role toward reframing rather than gap filling.

## Conclusion

The research reframes "joint space" from a fused vector into a contract between two coordinate systems. Anchors give the shared address, the grounding map says which traits the language can vouch for, and code is the final word on where every proposal lands. This changes what counts as progress. The first deliverable is not a better embedding but the grounding map, and every later piece is parameterized by it: the boundary's consistency test, the shape of gap prompts, and how natural-language user input is converted. It also makes the semantic side's weak results productive rather than disqualifying, because an uncarried axis tells the generator exactly what it must state explicitly, which is the core contribution's rule that weak semantics "locates what still needs grounding".

The decisive uncertainty is whether anchor-based translation works at 15 anchors. Experiments 2 and 3 settle that cheaply, and their results set the growth rule: if translation improves as verified LLM proposals join the anchor set, then the system's own exploration strengthens its grounding over time. That self-reinforcing loop, rather than the static fusion of two spaces, is the property worth claiming and testing.
